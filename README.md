# Casa Jardín — Proyecto completo

TP final de Técnico Superior en Logística (ISFT 151, Mar del Plata) — Belén Suárez, 2026.
Implementación de Odoo en Casa Jardín, local de venta y reparación de máquinas de jardín.

## Cómo usar con Claude Code
Abrí esta carpeta en Claude Code. El archivo `CLAUDE.md` se carga solo y le da a Claude todo el contexto: quién sos, cómo querés las respuestas, el proyecto y el estado de Odoo.

## Lo que no se pudo migrar
- **Las conversaciones del Proyecto en claude.ai** no se pueden exportar desde acá. Lo importante de ellas está resumido en `docs/memoria_proyecto.md` y `docs/registro_odoo.md`. Siguen disponibles en claude.ai.
- **El .docx original del TP** no estaba guardado como archivo en el Proyecto, solo su texto: está completo en `docs/TP_FINAL_SUAREZ.md`.
